# friday-stock-agents

ทีมนักวิเคราะห์หุ้นสหรัฐด้วย AI ห้าตัวที่ทำงานใน [Claude Code](https://claude.com/claude-code) อ่านเอกสารทางการของบริษัทแล้วเขียนเมโมวิเคราะห์เป็นภาษาไทย ทุกใบต้องผ่านเครื่องตรวจอัตโนมัติ

> **คำเตือน:** โปรเจกต์นี้ทำเพื่อการศึกษา ไม่ใช่คำแนะนำการลงทุน และไม่แนะนำซื้อหรือขายหุ้นตัวใด ผลงานสร้างโดย AI จึงอาจผิดพลาดได้ ต้องตรวจสอบกับแหล่งข้อมูลต้นทางเสมอ การตัดสินใจลงทุนเป็นความรับผิดชอบของคุณเอง

## ทีมวิเคราะห์

| เอเจนต์ | ตอบคำถาม |
|---|---|
| **tony (โทนี่)** | บริษัทหาเงินจากอะไร |
| **tommun (ทอมมุน)** | งบการเงินบอกอะไร กำไรเป็นเงินจริงแค่ไหน |
| **rob (ร็อบ)** | อะไรกันคู่แข่ง กำแพงนั้นหนาขึ้นหรือบางลง |
| **adam (อดัม)** | ผู้บริหารเข้าข้างผู้ถือหุ้นรายย่อยไหม ทำได้ตามที่พูดไหม |
| **damon (เดมอน)** | มูลค่าที่ประเมินได้ห่างจากราคาตลาดแค่ไหน |

มีสกิลเสริมสองตัว คือ `investment-thesis-synthesis` รวมเมโมทั้งห้าเป็นรายงานเดียว และ `portfolio-risk` ตรวจความเสี่ยงของพอร์ตหุ้นสหรัฐ

## ดูตัวอย่างโดยไม่ต้องติดตั้ง

ดูเมโมจริงของ Hilton ได้ที่ [examples/HLT](examples/HLT)

## สิ่งที่ต้องมี

- เครื่อง **Mac** (ระบบเก็บ key ใช้ Keychain ของ Mac จึงยังไม่รองรับ Windows)
- **Claude Code** และแพ็กเกจที่ใช้โมเดล Opus ได้ เอเจนต์หนึ่งตัวอ่านเอกสารยาวมาก จึงใช้โควตาสูง
- **uv** ติดตั้งด้วย `brew install uv`
- **FRED API key** ฟรี ใช้ดึงอัตราดอกเบี้ยและข้อมูลเศรษฐกิจ
- **FMP API key** แผนฟรีใช้ได้แต่ข้อมูลบางส่วนจำกัด ถ้าไม่มี คำสั่งดึง ratio และ estimates จะใช้ไม่ได้
- **Alpha Vantage key** ไม่บังคับ ใช้เป็นแหล่งราคาสำรอง
- **อีเมลของคุณ** SEC บังคับให้ระบุเมื่อดึงงบการเงิน

## วิธีติดตั้ง

```bash
# คัดลอกโปรเจกต์ลงเครื่อง
git clone https://github.com/exsexy5163-beep/friday-stock-agents.git
cd friday-stock-agents

# ติดตั้งโปรแกรมเสริม และกรอก key กับอีเมล (รันซ้ำได้)
./setup.sh

# เปิด Claude Code ในโฟลเดอร์นี้
claude
```

วางโปรเจกต์ไว้ในโฟลเดอร์ที่ path **ไม่มีช่องว่าง** ถ้าย้ายโฟลเดอร์ภายหลังให้รัน `./setup.sh` อีกครั้ง

ครั้งแรก Claude Code จะถามว่าอนุญาต MCP server (ตัวดึงข้อมูลตลาดของโปรเจกต์) ไหม ให้ตอบอนุญาต

## วิธีใช้

พิมพ์คำถามภาษาไทยใน Claude Code เช่น

- `ให้ tony ชำแหละธุรกิจของ AAPL`
- `ให้ tommun อ่านงบของ COST`
- `ให้ rob วัดคูเมืองของ V`

เมโมจะถูกบันทึกไว้ใน `outputs/<ชื่อเอเจนต์>/` รองรับเฉพาะบริษัทจดทะเบียนในสหรัฐ

## ทำงานอย่างไร

- **ข้อมูล:** เรียงความน่าเชื่อถือจาก SEC EDGAR, FRED, FMP, แล้วจึงแหล่งรอง ทุกตัวเลขระบุที่มาและวันที่
- **การอ่าน:** เอเจนต์ต้องส่งใบเสร็จยืนยันว่าอ่านเอกสารครบ
- **การตรวจ:** เครื่องตรวจใน `tools/memocheck` ตรวจโครงสร้าง ที่มา และคำต้องห้าม ใบที่ไม่ผ่านจะไม่ถูกส่งต่อ แต่การผ่านไม่ได้พิสูจน์ว่าเหตุผลถูกต้อง

## ข้อจำกัด

- รองรับเฉพาะ Mac และหุ้นสหรัฐ
- โปรเจกต์นี้ปล่อยเป็นเวอร์ชันเดียว ไม่มีการอัปเดตต่อเนื่อง
- ผู้ดูแลไม่ได้ตรวจความถูกต้องของผลวิเคราะห์ที่คุณสร้างเอง
