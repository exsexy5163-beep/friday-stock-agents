# ชุดทดสอบของ `adam_check.py`

ไฟล์ในนี้เป็น **เมโมสมมติ** — บริษัท `FKG / Fixture Governance Corp.` และคนในนั้น
(เอ. / บี. / ซี. ฟิกซ์เจอร์) **ไม่มีอยู่จริง** ตัวเลขทุกตัวแต่งขึ้นให้ **ผูกกันทางคณิตศาสตร์**
เพื่อให้เครื่องตรวจคิดซ้ำได้จริง

> **ข้อควรระวังที่หนักกว่าชุดของอีกสามเอเจนต์:** เมโมของอดัมพูดถึง **คนจริง** เวลาใช้งานจริง
> ตัวอย่างในนี้จึงตั้งใจใช้ชื่อสมมติที่ดูออกทันทีว่าไม่ใช่คนจริง — **ห้ามคัดลอกประโยคตัดสิน
> ในไฟล์เหล่านี้ไปใช้กับบริษัทจริงโดยไม่เปลี่ยนหลักฐาน**

รันทั้งชุด:

```bash
# ไล่ตรวจทุกไฟล์ในชุด แล้วพิมพ์ PASS/FAIL ทีละบรรทัด
for f in scratch/adam-check-fixtures/*.md; do
  printf '%-30s ' "$(basename $f)"
  __FRIDAY_ROOT__/.venv-utils/bin/python tools/adam_check.py "$f" >/dev/null 2>&1 \
    && echo PASS || echo FAIL
done
```

## ต่างจากชุดของร็อบตรงไหน (สำหรับคนที่เทียบสองชุด)

- อดัมมี **2 ตารางในภาคผนวก** ไม่ใช่ 3 (ไม่มีตารางคู่แข่ง เพราะอดัมไม่เทียบบริษัท
  เขาเทียบ **คำพูดกับการกระทำ** ของคนในบริษัทเดียว) → แถว 6 ช่องที่ร็อบอ่านเป็น
  "ตารางคู่แข่ง" อดัมจะ FAIL ทันที ซึ่งคือสิ่งที่ `bad-appendix6col.md` พิสูจน์
- **Bull/Bear บังคับเฉพาะ §7** ไม่ใช่ §2/§4/§7 แบบร็อบ — §1–§6 ของอดัมเป็นการไล่ข้อเท็จจริง
  ตามเอกสาร ไม่ใช่จุดตัดสิน บังคับสองฝั่งทุก section จะได้ Bull/Bear ปลอมมาเติมให้ผ่าน
- อดัมบังคับ **ตารางสองใบในเนื้อเมโม** (PROMISE vs DELIVERY ใน §2 · Scorecard ใน §7)
  ร็อบไม่บังคับตารางในเนื้อเลย บังคับแค่บรรทัด

## ชุดนี้พิสูจน์อะไร และ **ไม่** พิสูจน์อะไร (อ่านก่อนเอาไปอ้าง)

**พิสูจน์:** กฎทุกข้อในเครื่องตรวจของอดัมทำงานตามที่เขียนไว้ — จับผิดได้ตรงจุด
และไม่ FAIL เมโมที่ถูกต้อง

**ไม่พิสูจน์ 5 อย่าง — สี่ข้อแรกซ้ำกับชุดอื่น ข้อสุดท้ายเป็นของอดัมโดยเฉพาะ:**

1. **ว่าเมโมจริงจะผ่าน** — `good.md` เขียนโดยคนที่รู้กฎอยู่แล้วและไม่ต้องไปเปิด DEF 14A จริง
2. **ว่าเนื้อหาครบตามพรอมต์** — เครื่องตรวจไม่รู้ว่าอดัมอ่านหัวข้อรายการเกี่ยวโยงจริงหรือเปล่า
3. **ว่าคำตัดสินสืบย้อนได้จริง** — `alignment_verdict_basis` ห้ามว่างแล้ว แต่ยังไม่ตรวจว่า
   ข้อความในนั้นตรงกับ §3/§5 จริงไหม **ตัวหลักต้องอ่าน §7 ด้วยตา**
4. **ว่า Bull/Bear สมดุล** — เขียน Bear ลอย ๆ บรรทัดเดียวก็ผ่าน
5. **ว่าข้อความเกี่ยวกับคนจริงปลอดภัยทางกฎหมาย** — เครื่องตรวจไม่รู้จักการหมิ่นประมาท
   มันกันได้แค่ทางอ้อมด้วยการบังคับ Bull/Bear และการบังคับให้ **ทุกแถว** ของ Scorecard
   มีที่อ้างในแถวนั้น (ตั้งแต่ 2026-09-01 — ก่อนหน้านั้นบังคับแค่ชื่อช่องในแถวหัว)
   **ความรับผิดชอบข้อนี้อยู่ที่อดัมและตัวหลัก ไม่ใช่ที่สคริปต์**
