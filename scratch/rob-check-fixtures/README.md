# ชุดทดสอบของ `rob_check.py`

ไฟล์ในนี้เป็น **เมโมสมมติ** — บริษัท `FKA / Fixture Moat Corp.` และคู่แข่ง `FKB` `FKC` `FKD`
ไม่มีอยู่จริง ตัวเลขทุกตัวแต่งขึ้นให้ **ผูกกันทางคณิตศาสตร์** เพื่อให้เครื่องตรวจคิดซ้ำได้จริง
**ห้ามอ้างอิงตัวเลขในนี้เป็นข้อมูลบริษัทใด ๆ**

รันทั้งชุด:

```bash
for f in scratch/rob-check-fixtures/*.md; do
  printf '%-24s ' "$(basename $f)"
  __FRIDAY_ROOT__/.venv-utils/bin/python tools/rob_check.py "$f" >/dev/null 2>&1 \
    && echo PASS || echo FAIL
done
```

**bad-* ทุกไฟล์สร้างจาก `good.md` โดยแก้จุดเดียว** — ถ้าแก้ `good.md` ต้องสร้าง bad-* ใหม่ด้วย

> **`bad-peercols.md` อ่านข้อความ FAIL ให้ดี** — มันไม่ได้บอกว่า "ตารางคู่แข่งช่องไม่ครบ"
> แต่บอกว่า "ดึงตัวเลขจากช่องไม่ได้" ในตาราง **คำนวณ** เพราะภาคผนวกจำแนกตารางด้วย
> **จำนวนช่อง** ล้วน ๆ — 6 ช่อง = คู่แข่ง · 5 ช่อง = คำนวณ · 4 ช่อง = ที่มา
> เขียนจำนวนช่องผิดเมื่อไหร่ ข้อความ FAIL จะชี้ไปผิดตาราง นี่เป็นข้อจำกัดของ `core.py`
> ที่ทั้งสามเอเจนต์เจอเหมือนกัน ไม่ใช่บั๊กเฉพาะของร็อบ
>
> **`bad-peercols7.md` คือด้านตรงข้าม** — ก่อน 2026-09-01 ตารางคู่แข่งตั้ง `max_cols=None`
> จึงเป็น "ถังรับตก" ของทุกตารางที่กว้างตั้งแต่ 6 ช่องขึ้นไป ตารางที่พิมพ์เกินเป็น 7 ช่อง
> จึงถูกอ่านเป็นตารางคู่แข่งเงียบ ๆ และ **PASS** ตอนนี้ล็อกเป็น 6 ช่องพอดีแล้ว

## ชุดนี้พิสูจน์อะไร และ **ไม่** พิสูจน์อะไร (อ่านก่อนเอาไปอ้าง)

**พิสูจน์:** กฎทุกข้อในเครื่องตรวจของร็อบทำงานตามที่เขียนไว้ — จับผิดได้ตรงจุด
และไม่ FAIL เมโมที่ถูกต้อง

**ไม่พิสูจน์ 4 อย่าง:**

1. **ว่าเมโมจริงจะผ่าน** — `good.md` เขียนโดยคนที่รู้กฎอยู่แล้วและไม่ต้องไปดึงข้อมูลจริง
   เมโมจริงต้องผ่านการอ่าน 10-K + ดึงงบคู่แข่งสามราย + ค้น TAM จากเว็บ ซึ่งเป็นคนละงานกัน
2. **ว่าเนื้อหาครบตามพรอมต์** — เครื่องตรวจดูโครงสร้าง ไม่ได้นับว่าไล่ครบห้าแหล่งคูเมืองใน §2
   หรือครบห้าแรงใน §3 จริงไหม
3. **ว่าคำตัดสินสืบย้อนได้จริง** — ตั้งแต่ 2026-09-01 กฎบังคับว่า `moat_rating_basis`
   ต้องมีและ **ห้ามเป็นค่าว่าง** แต่ยังไม่ได้ตรวจว่าข้อความใน `_basis` ตรงกับสิ่งที่เขียนไว้
   ใน §2/§4 จริง **ตัวหลักต้องอ่าน §7 ด้วยตา**
4. **ว่าการเทียบคู่แข่งชอบธรรม** — คอลัมน์ "เทียบได้ไหม" บังคับให้ **เขียน** แต่เครื่องตรวจ
   ไม่รู้ว่านิยามต้นทุนของสองบริษัทตรงกันจริงหรือเปล่า
