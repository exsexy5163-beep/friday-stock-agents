# VALUATION MEMO — NWSY

## §0 THE VALUATION SETUP & METHOD CHOICE

**นิยามมูลค่ากิจการ (EV) ที่ใช้ทั้งเมโมนี้ตัวเดียว (V33):**
`EV = มูลค่าตลาดส่วนของผู้ถือหุ้น + หนี้ขั้นต้น − เงินสด − หลักทรัพย์ในความต้องการของตลาด`
ทุกตัวคูณในเมโมนี้ใช้นิยามนี้ ไม่มีที่ไหนสลับไปใช้นิยามที่หักสินทรัพย์นอกการดำเนินงานเพิ่ม

Northwind Systems ขายซอฟต์แวร์บริหารคลังสินค้าแบบสมัครสมาชิก รายได้เกือบทั้งหมดเป็นค่าสมาชิกรายปี
ธุรกิจไม่ใช่สถาบันการเงินและไม่ใช่กองทรัสต์อสังหาริมทรัพย์ จึงใช้ **FCFF คิดลดด้วย WACC** เป็นวิธีหลัก
ตัวคูณเทียบเคียงหลักเลือก **P/OCF** เพราะบริษัทยังลงทุนเพื่อโตทำให้กระแสเงินสดอิสระต่ำหลอกตา
และปฏิเสธ P/S ตามกติกาเพราะไม่บอกอะไรเรื่องความสามารถทำกำไร ปฏิเสธ P/E เพราะกำไรสุทธิถูกรบกวน
จากรายการครั้งเดียวในปีฐาน

เรื่องราวที่จะแปลเป็นตัวเลข: ฐานลูกค้าเดิมต่ออายุสูง ทำให้รายได้โตต่อได้ราวเลขสองหลักต้น ๆ
อีกสามปี แล้วค่อยเข้าสู่สภาวะคงตัว

(ความเห็น: FCFF เหมาะกับธุรกิจนี้เพราะโครงสร้างทุนมีหนี้อยู่จริงและกระแสเงินสดก่อนดอกเบี้ยคาดการณ์ได้)

## §5 TERMINAL VALUE STRESS

**ผูก ROIC ปลายทางกับงบดุลที่ช่วงชัดเจนสร้าง (V28):** เดินเส้นสินทรัพย์
`PP&E สุทธิ_t = PP&E สุทธิ_{t−1} + เงินลงทุน_t − ค่าเสื่อม_t` ถึงปีสุดท้ายได้ 4,180 ล้าน USD
บวก NWC ปลายทาง 240 ล้าน USD → **เงินทุนที่ลงไปปลายทาง = 4,420 ล้าน USD**
`ROIC โดยนัย = NOPAT ปลายทาง 619 ÷ 4,420 = 14.00%` ตรงกับ ROIC ปลายทางที่ใส่ในสูตร ไม่มีส่วนต่าง

รายได้ต่อลูกค้าต่อปี 1,340 USD ในปีสุดท้าย หรือ 1.18 เท่าของวันนี้ — **ต่ำกว่าค่าเฉลี่ยสามปี
ที่ผ่านมา** จึงอ่านว่า *ทำได้ไม่ยาก* ไม่ใช่ *เป็นไปไม่ได้*

**แก้ย้อนอีกทิศ (V25):** เมื่อ **ตรึงมูลค่าปลายทาง** ไว้ที่ค่าของโมเดลแล้วแก้หากระแสเงินสด
ช่วงชัดเจน พบว่าราคาต้องการกระแสเงินสดสิบปีต่ำกว่าโมเดล 6.10% → **สัดส่วนของช่องว่างขึ้นกับ
