# Output Contract — รายงาน Investment Thesis

สัญญานี้คือสิ่งที่ `scripts/check_report.py` ตรวจ (ส่วนที่ตรวจด้วยเครื่องได้) บวกกติกาเชิงเนื้อหาที่เครื่องตรวจไม่ได้
ถ้าจะเปลี่ยนสัญญา ต้องแก้ทั้งไฟล์นี้และเครื่องตรวจพร้อมกัน

## 1. ไฟล์และ YAML header

path: `outputs/investment-thesis/<TICKER>-YYYY-MM-DD.md` (วัน = `run_date`) หรือ `...-YYYY-MM-DD-HHMM.md` ถ้าชื่อซ้ำ

YAML ต้องเป็น **key: value บรรทัดเดียวแบบแบน** (ไม่มี list/nested) เพราะเครื่องตรวจ parse เอง ไม่ใช้ PyYAML
ห้ามครอบค่าด้วยเครื่องหมายคำพูดโดยไม่จำเป็น

```yaml
---
ticker: XYZ
company: Example Corp.
generated_at: 2026-09-13T21:40:00+07:00
run_date: 2026-09-13
memo_tony: outputs/tony/XYZ-2026-09-03.md
memo_tony_as_of: 2026-09-03
memo_tommun: outputs/tommun/XYZ-2026-09-04.md
memo_tommun_as_of: 2026-09-04
memo_rob: outputs/rob/XYZ-2026-09-04.md
memo_rob_as_of: 2026-09-04
memo_adam: outputs/adam/XYZ-2026-09-04.md
memo_adam_as_of: 2026-09-04
memo_damon: outputs/damon/XYZ-2026-09-05.md
memo_damon_as_of: 2026-09-05
current_price: 123.45 USD
price_date: 2026-09-11
price_retrieved_at: 2026-09-13
price_source: yfinance ผ่าน friday-marketdata-mcp get_price_history
price_tier: tier3
valuation_price: 120.00 USD
valuation_price_date: 2026-09-04
stance: ควรรอ
confidence: ปานกลาง
confidence_limits: ข้อจำกัดที่กดความมั่นใจลง เขียนเป็นประโยคเดียว
---
```

กติกา:

- memo path เป็น path สัมพัทธ์จาก root ของ workspace friday และต้องชี้ไฟล์ที่มีอยู่จริง
  `memo_<agent>_as_of` ต้องตรงกับ `as_of` ใน YAML ของไฟล์มีโม่ และอายุ ≤ 90 วันนับถึง `run_date`
- `price_retrieved_at` = วันที่ดึงจริงในรอบนี้ = `run_date` (กันการยกผลดึงเก่ามาใช้)
- **ดึงราคาไม่ได้:** `current_price`, `price_date`, `price_tier` = `[ยังไม่มีข้อมูล]` ·
  `price_retrieved_at` ยังเป็นวันที่พยายามดึง · `stance` ห้ามเป็น `น่าสนใจ`
  และห้ามใส่ราคาจากมีโม่ในช่อง `current_price`
- `valuation_price` / `valuation_price_date` = ราคาและวันที่มีโม่ damon ใช้ (ถ้าไม่มีให้ `[ยังไม่มีข้อมูล]`)
- `stance` ∈ `น่าสนใจ` · `ควรรอ` · `ควรหลีกเลี่ยง` — เป็นคำตัดสินเรื่อง **หุ้น ณ ราคาที่ตรวจได้** ไม่ใช่เรื่องคุณภาพบริษัท
  - `น่าสนใจ` = มีราคาปัจจุบันที่ตรวจได้ + valuation ที่ผ่านการตรวจขั้นที่ 7 แล้วยังเหลือส่วนเผื่อความผิดพลาดโดยไม่ต้องให้ทุกสมมติฐานฝั่งดีเป็นจริงพร้อมกัน
  - `ควรรอ` = ธุรกิจอาจดี แต่ยังพิสูจน์ความคุ้มราคาไม่ได้ หรือข้อมูลราคา/valuation ไม่พอ
  - `ควรหลีกเลี่ยง` = ข้อต่อในโซ่ธุรกิจขาด (thesis ไม่ยืน) หรือราคาเรียกร้องสิ่งที่หลักฐานขัดแย้งอยู่
- `confidence` ∈ `สูง` · `ปานกลาง` · `ต่ำ` และ `confidence_limits` ห้ามว่าง

## 2. ป้ายที่มา (provenance labels)

ติดป้ายในวงเล็บเหลี่ยมหน้าข้อความ ใช้ **ทั้งสี่ป้ายอย่างน้อยหนึ่งครั้ง** ในรายงาน และติดทุกข้ออ้างที่รับน้ำหนัก

| ป้าย | ใช้เมื่อ |
|---|---|
| `[ข้อเท็จจริง]` | เอกสารต้นทางรองรับตรง ๆ (filing, ข่าวบริษัท, ข้อมูลราคา) — ต้องมีการอ้างอิงตามหลัง |
| `[การตีความ]` | ความหมายที่เอเจนต์คนใดคนหนึ่งให้กับข้อมูล — อ้างมีโม่และ § |
| `[สมมติฐาน]` | สิ่งที่ยังต้องเกิดในอนาคต รวมถึง input ของโมเดล valuation |
| `[ข้อสังเคราะห์ใหม่]` | ข้อสรุปของผู้สังเคราะห์ที่ไม่มีมีโม่ใบใดพูดไว้ — ห้ามเขียนราวกับเป็นความเห็นของเอเจนต์ |

## 3. การอ้างอิง

- ในเนื้อหา: `[outputs/<agent>/<TICKER>-YYYY-MM-DD.md §N]` (หลาย § คั่นด้วย `–` หรือ `,`) ตามด้วยต้นทางถ้ามี
  เช่น `[outputs/tommun/XYZ-2026-09-04.md §3; 10-K FY2025 Item 8, tier1]`
- **มีโม่ทั้งห้าใบต้องถูกอ้างในรูปนี้อย่างน้อยหนึ่งครั้ง** — ถ้าอ้างไม่ได้สักครั้ง แปลว่าข้อต่อนั้นไม่ได้ถูกใช้จริง
- ตัวเลขที่คำนวณเองระบุว่า "คำนวณด้วย Decimal จาก ..."
- ท้ายรายงานมีหัวข้อ `## แหล่งอ้างอิง` เรียงเลข: ชื่อเอกสาร · form/accession หรือผู้เผยแพร่ · tier · วันที่ดึงตรวจ · URL (`https://...`)
  มีโม่ห้าใบไม่ต้องมี URL แต่ต้องอยู่ในรายการด้วย path

## 4. `[ยังไม่มีข้อมูล]`

ใช้เมื่อไม่มีหลักฐานหรือดึงไม่ได้ **แทนการเดา** — ไม่ใช่คำว่า "บริษัทไม่เปิดเผย"
(ถ้าดึงล้มให้เขียนว่าดึงไม่สำเร็จ) และห้ามแทนที่ด้วยตัวเลขประมาณที่ไม่มีการคำนวณรองรับ

## 5. โครงสร้างเนื้อหา (บังคับ เรียงตามนี้ ใช้หัวข้อระดับ `##` ตรงตัวอักษร)

```
# <TICKER> — Investment Thesis (<run_date>)

## A. ข้อสรุปก่อนอ่านรายละเอียด
## B. Investment Thesis หลัก
## C. เสาหลักของ Thesis
## D. จุดที่มีโม่เห็นตรงกันและขัดแย้งกัน
## E. ราคาหุ้นกำลังเรียกร้องอะไร
## F. Bear Case ที่แข็งแรงที่สุด
### F1. เหตุการณ์ที่ทำให้ thesis ผิด
### F2. เหตุการณ์ที่ทำให้กำไรสะดุดชั่วคราว
### F3. ผลตอบแทนต่ำเพราะซื้อแพง แม้ธุรกิจยังดี
## G. เงื่อนไขตัดสินใจและสิ่งที่ต้องติดตาม
## H. อธิบายแบบภาษาคน
## แหล่งอ้างอิง
```

### A. ข้อสรุปก่อนอ่านรายละเอียด
บูลเล็ตที่ขึ้นต้นด้วยป้ายเหล่านี้ (เครื่องตรวจหาสองอันแรกตรงตัว):
- **บริษัทดีหรือไม่:** ... เพราะอะไร
- **หุ้นคุ้มราคาหรือไม่:** ... ณ ราคาที่ตรวจได้ (ราคา · วันราคา · วันที่ดึง · tier) หรือ `[ยังไม่มีข้อมูล]` พร้อมผลต่อข้อสรุป
- **เหตุผลหลักที่ควรลงทุน** / **เหตุผลหลักที่ควรหลีกเลี่ยง**
- **stance:** ค่าเดียวกับ YAML · **ความเชื่อมั่น:** ค่าเดียวกับ YAML + ข้อจำกัด
- **ความสดของข้อมูล:** ตารางมีโม่ห้าใบ (agent · path · as_of · filing หลัก · วันราคาที่มีโม่ใช้) + ราคาปัจจุบัน
  + ระบุช่วงเวลาที่ไม่ตรงกันระหว่างมีโม่

### B. Investment Thesis หลัก
ย่อหน้าสั้น: เชื่อว่าอะไรจะเกิด · ผ่านกลไกใด · ในกรอบเวลาใด · ทำไมจึงให้ผลตอบแทนต่อผู้ถือหุ้น **เทียบกับราคาที่จ่าย**
ถ้าไม่มีหลักฐานว่าตลาดประเมินผิด ให้เขียนตรง ๆ

### C. เสาหลักของ Thesis
เฉพาะเสาที่จำเป็นต่อผลลัพธ์ (ปกติ 3–5) แต่ละเสามี: สิ่งที่เชื่อ · กลไกสู่กำไร/เงินสด/มูลค่าต่อหุ้น ·
หลักฐานสนับสนุน (อ้างอิง) · หลักฐานคัดค้าน/จุดอ่อน · สิ่งที่ต้องเป็นจริงต่อไป · ตัวชี้วัดติดตาม
เสาควรไล่ตามโซ่: คุณค่าลูกค้า → ความยากในการแย่ง → กำไรเป็นเงินสด → การจัดสรรเงิน → มูลค่าต่อหุ้น

### D. จุดที่มีโม่เห็นตรงกันและขัดแย้งกัน
เฉพาะจุดที่เปลี่ยนการตัดสินใจได้ · บอกว่าต่างเพราะ ข้อมูล / สมมติฐาน / กรอบเวลา / นิยาม / การตีความ ·
ให้น้ำหนักฝั่งไหนเพราะอะไร · อย่างน้อยหนึ่งจุดที่ "เห็นตรงกันแต่เป็นหลักฐานตระกูลเดียว" ·
ตัดสินไม่ได้ → หลักฐานที่ต้องหาเพิ่ม

### E. ราคาหุ้นกำลังเรียกร้องอะไร
- สถานะ valuation: วันราคาของโมเดล vs ราคาปัจจุบัน · ผลตรวจขั้นที่ 7 ที่เปลี่ยนน้ำหนักข้อสรุป
- ตัวเลขจากมีโม่ damon ติดป้าย `[สมมติฐาน]` และเขียนว่าเป็น "ผลโมเดล ณ วันที่ ..." ไม่ใช่ราคาเป้าหมายใหม่
- ธุรกิจต้องทำได้แค่ไหน · ส่วนไหนมีหลักฐาน ส่วนไหนต้องหวัง · ถ้าธุรกิจดีแต่โตช้ากว่าคาด เสียหายผ่านช่องทางใด
- ห้ามสร้างราคาเป้าหมายหรือผลตอบแทนคาดหวังใหม่

### F. Bear Case ที่แข็งแรงที่สุด
ข้อโต้แย้งที่ฝั่งไม่ซื้อใช้จริง ไม่ใช่ลิสต์ความเสี่ยงทั่วไป แยก F1/F2/F3 ตามหัวข้อ
F2 ต้องบอกว่าจะรู้ได้อย่างไรว่า "ชั่วคราว" จริง

### G. เงื่อนไขตัดสินใจและสิ่งที่ต้องติดตาม
เงื่อนไขที่ทำให้ `น่าสนใจ` · เงื่อนไขที่ `ควรรอ` · หลักฐานที่ทำให้เปลี่ยนใจ (บวก/ลบ) · ตัวชี้วัดสำคัญจริงไม่เกิน ~5 กลุ่ม
threshold ที่ไม่มีหลักฐานรองรับ → `[ยังไม่มีข้อมูล]` + ทิศทางที่ต้องติดตาม

### H. อธิบายแบบภาษาคน
สำหรับนักลงทุนมือใหม่: เรากำลังเดิมพันกับอะไร · ทำไมอาจได้ผล · อาจผิดตรงไหน · ราคาที่จ่ายสำคัญอย่างไร
อธิบายศัพท์เทคนิคในวงเล็บครั้งแรก ห้ามใช้คำว่า "ถูก/แพง" ในความหมาย "ซื้อ/ขาย"
